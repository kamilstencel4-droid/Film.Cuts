Účel, autor a technické informace

Proč tento web

Tento web slouží jako prezentační portfolio pro Film.Cuts — projekty, ukázky práce, kontakty a informace o týmu. Je navržen tak, aby byl rychlý, jednoduchý na údržbu a přehledný pro návštěvníky i pracovní partnery.

Autor

Kamil Štencel — režisér, kameraman a editor. Kontakt a sociální sítě jsou uvedeny v sekci Kontakt.

Technologie

Statický web postavený pomocí HTML, CSS a drobného JavaScriptu. Zdrojové soubory jsou jednoduché a snadno upravitelné — žádný backend, rychlé načítání a nízké nároky na hosting.
