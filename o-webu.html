Detaily projektu

HTML struktura

Sémantické HTML5 značky, přístupná navigace (ARIA), responsivní layout s CSS Grid a Flexbox.

Styly

Jednotný design systém s CSS custom properties (proměnné), tmavý a světlý režim, optimalizované animace a přechody.

Interaktivita

Vanilkový JavaScript bez externích knihoven. Lightbox galerie, navigační menu, smooth scrolling a lazy loading obrázků.

Výkonnost

Optimalizované obrázky, minimalizované CSS a JS, cache strategie. Cíl: rychlé načítání i na pomalejších připojeních.
